One fix, mended for reuse

A cracked pot mended with gold seams is stronger at the break. Kintsugi treats a bug the same way: the repair itself becomes the valuable part.

  1. Diagnose

    A Run begins with one sentence: the Root Cause Hypothesis — the kind of mistake this looks like, never where it happens or how it surfaces.

  2. Ask the Registry

    That hypothesis goes to the shared Skill Registry. The Registry, not the agent, decides the next step: reuse or research.

  3. Reuse or research

    A match installs the winning Skill's strategy outright. No match means reading primary sources and building a fix from scratch.

  4. Verify, then publish

    A fix only counts once its tests pass. A verified Research Path fix becomes a new Skill, pushed for the next agent to reuse.

Join the shared Registry

The Registry is a standalone MCP server. Point any Claude Code or Agent SDK client at it, or skip the server entirely and install the Skills as plain files.

Run the Registry over MCP

KINTSUGI_SKILLS_REMOTE=https://github.com/arnv15/kintsugi-skills.git \
  uvx --from "git+https://github.com/arnv15/Kintsugi#subdirectory=registry" kintsugi-registry

Or install Skills as plain files

git clone https://github.com/arnv15/kintsugi-skills .claude/skills/kintsugi
