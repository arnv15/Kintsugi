## Agent skills

### Issue tracker

Issues and PRDs live in this repo's GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default five-label triage vocabulary. See `docs/agents/triage-labels.md`.

### Architecture docs

After a ticket changes a module, interface, data flow, or dependency, update the relevant `docs/architecture/` page and Mermaid map before committing.
